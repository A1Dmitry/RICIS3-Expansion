## 2026-08-04 — Итерация: agent JSON error on Pages (v0.3.26)

- Ошибка агента при поиске новых задач: `Unexpected token '<', "<html> <he"... is not valid JSON`.
  **Причина:** GitHub Pages раздаёт только статический бандл; `fetch('/api/discoverTasks')` получает HTML (SPA fallback), а не JSON Express API.
  **Исправление:**
  - `src/model/apiClient.ts` — безопасный `postJson`: детект HTML / non-JSON, понятное сообщение на русском.
  - `agent.ts`, `audit.ts`, `logic.ts`, `AddNodeModal.tsx` переведены на `postJson`.
  - Offline structural fallback в `discoverNewProblems` (сведение к RICIS-ядру + метрика устойчивости), чтобы graph-walk работал и без LLM на Pages.
  - Полный LLM-агент по-прежнему доступен при `npm run dev` с `GEMINI_API_KEY`.
  **Статус:** исправлено (v0.3.26).
