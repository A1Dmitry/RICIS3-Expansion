# RICIS-III Expansion — Карта сингулярности

Интерактивная 3D-карта проблем сингулярности с формальным ядром **RICIS-III** (Recursive Indexed Calculus of Identity and Singularity).

Проект визуализирует сеть нерешённых и частично решённых задач (узлов), зависимости между ними, научные зоны и экономические оценки. Пользователь может «решать» узлы, получать формальные аксиомы и наблюдать фрактальный рост карты.

## Возможности

- **3D-навигация** (стандартная мышь):
  - ЛКМ — вращение (orbit)
  - ПКМ / СКМ — панорамирование
  - Колесо — масштабирование
- Интерактивные узлы проблем с цветовой индикацией состояния:
  - красный — `unresolved`
  - жёлтый — `partial`
  - зелёный — `resolved`
- Оверлей узла: описание, целевая функция, экономические показатели, кнопка «Решить»
- Генерация формального доказательства (LaTeX) и аксиомы при решении узла
- Фрактальное расширение: после решения появляются новые зависимые задачи
- Научные зоны (математика, информатика, медицина, фармакология, физика, экономика, этика)
- Экономический профиль: ущерб нерешённости, стоимость решения, рыночная выгода, риск

## Быстрый старт (тестовый сервер)

### Требования

- Node.js 20+ (рекомендуется)
- npm / bun / pnpm

### Установка

```bash
git clone https://github.com/A1Dmitry/RICIS3-Expansion.git
cd RICIS3-Expansion
npm install
```

### Режим разработки (тестовый сервер)

```bash
npm run dev
```

Сервер запускается на `http://0.0.0.0:3000`  
(доступен локально и из локальной сети).

### Сборка и preview (продакшен-подобный тест)

```bash
npm run build
npm run start          # или npm run preview
```

Сервер preview: `http://0.0.0.0:4173`

### Проверка типов

```bash
npm run lint
```

## Структура проекта

```
src/
  model/
    types.ts          # Формальные типы (ProblemNode, DependencyEdge, ScienceZone, Axiom, MapState)
    initialMap.ts     # Начальная карта сингулярностей
    logic.ts          # Логика решения узла + фрактальное расширение + генерация proof
  store/
    mapStore.ts       # Zustand-хранилище состояния карты
  ui/
    Map3D.tsx         # 3D-сцена (react-three-fiber) + UI-оверлеи
  App.tsx
  main.tsx
  index.css
```

## Модель данных (кратко)

| Сущность          | Назначение                                      |
|-------------------|-------------------------------------------------|
| `ProblemNode`     | Узел проблемы (состояние, целевая функция, экономика) |
| `DependencyEdge`  | Луч зависимости (цвет, сила, экономическое влияние)   |
| `ScienceZone`     | Зона науки с агрегированным экономическим профилем    |
| `Axiom`           | Формальная аксиома, полученная при решении узла       |
| `Proof`           | Пошаговое LaTeX-доказательство (фазы RICIS-III)       |

## Архитектура

1. **Ядро RICIS-III** (модель + logic) — формализация, вывод аксиом, фрактальный рост.
2. **3D-движок** — WebGL через `@react-three/fiber` + Three.js, стандартные OrbitControls.
3. **Состояние** — Zustand (`useMapStore`).
4. **UI** — Tailwind CSS + оверлеи, боковая панель зон, тикер статуса.
